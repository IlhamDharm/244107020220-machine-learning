## Cara Menjalankan Notebook

### 1. Clone repositori

```bash
git clone https://github.com/IlhamDharm/244107020220-machine-learning.git
```

### 2. Masuk ke direktori proyek

```bash
cd 244107020220-machine-learning
```

### 3. Siapkan lingkungan Python

Pastikan Python dan Jupyter Notebook sudah terpasang. Kamu dapat menggunakan lingkungan virtual agar dependensi proyek lebih terorganisasi.

```bash
python -m venv .venv
```

Aktifkan lingkungan virtual sesuai sistem operasi yang digunakan.

**Windows:**

```bash
.venv\Scripts\activate
```

**Linux / macOS:**

```bash
source .venv/bin/activate
```

### 4. Instal Jupyter Notebook

```bash
python -m pip install notebook
```

Instal juga pustaka tambahan yang dibutuhkan oleh notebook berdasarkan perintah `import` di masing-masing file.

### 5. Jalankan notebook

```bash
jupyter notebook
```

Pilih file TG1–TG6 yang ingin dipelajari, kemudian jalankan sel kode secara berurutan.
